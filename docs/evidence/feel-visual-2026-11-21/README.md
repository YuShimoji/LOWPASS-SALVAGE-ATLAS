## 変えたこと

| 段 | 内容 |
| --- | --- |
| B画面 | 場所ごとの照明（市場は暗い基調に暖色の壁灯・青緑の扉・赤い警報、船内は吊りランプと警報）、発光と周辺減光、水面の反射、床と壁の汚れ、棚の商品や浮遊物、監視機の橙の円錐とロックの赤いレーザー。表示設定に「水面の反射」「発光・周辺減光」を追加 |

| A操作感 | 加速（0→歩行速度 約0.13秒）と減速（約0.11秒）、反転時は強めの減速。最高速 `WALK_SPEED` 3.2 / `SPRINT_SPEED` 5.1 は不変。隊員を基準画像03準拠の姿に替え、歩行の手足の振り・上下動・前傾・旋回時の傾きと、向きの補間（最大13 rad/s）を追加。カメラの注視点をわずかに遅らせ、出撃直後の見下ろし角を約24°までに抑えた。視点の上下は、右ドラッグ・マウス・右スティックを上へ動かすと見上げる向き（本人の「カメラの上下がかなり違和感ある」で2026-11-21に反転） |

ゲームルール、Security Cell、保存（V2）、`ItemLocation`、collider、navigation は変えていない。

ソフトウェア描画（SwiftShader / Microsoft Basic Render など）では、描画が重いと固定ステップのシミュレーションまで遅くなるため、軽い描画（後処理・反射・装飾の灯り・影なし）に自動で切り替わる。診断の `renderTier` で確認できる。

## 通常の Chrome で手触りを確かめる手順

Claude desktop の内蔵ブラウザは 12〜26fps しか出ないので、手触りの判定には使わない。

1. PowerShell で `C:\Users\thank\Storage\Game Projects\LOWPASS-SALVAGE-ATLAS` に移動し、`npm run dev` を実行する。
2. 通常の Chrome で `http://localhost:5173/` を開く（`?qa=1` は付けない）。
3. 船内で確かめる:
   - W を軽く叩く／長押しして離す。走り出しと止まりが急すぎず、滑りすぎないか。
   - A と D を素早く切り替える。向きの回り方と体の傾きが自然か。
   - Shift で走る。歩きと走りで手足の振りが変わって見えるか。
   - 右ドラッグで視点を回し（上へ動かすと見上げる）、ホイールで距離を変える。カメラの遅れが酔いや鈍さにつながらないか。
4. 出撃コンソールで出撃し、市場で同じ操作をする。出撃直後の視点の高さ、隊員2人の歩き方、暗さの中で自分の隊員が読めるかを見る。
5. 右上の「Ⅱ」から表示設定を開き、「水面の反射」「発光・周辺減光」「頂点スナップ」を切り替えて違いを見る。
6. 違和感は「どの操作で・何がどう感じたか」の形で残す（例: 「D を押した直後、体が回り切る前に横へ滑って見える」）。
